アプリの画面は英語のままです。ここでは、画面に出る表記が何を指すかをまとめています。

## 画面の5つの領域

| 英語 | 日本語 | 役割 |
|------|--------|------|
| Tool Bar | ツールバー | 画面上部。ファイル操作、描画ツール、データ操作のボタンが並びます |
| Canvas | キャンバス | 図形を描き、選択し、動かす場所です |
| Data Panel | データパネル | 画面左下。読み込んだデータの表を表示します |
| Layers | レイヤー | キャンバス上の図形、グループ、軸、凡例の構成を表示します |
| Property Inspector | プロパティインスペクタ | 画面右側。選択した図形の見た目を変えたり、データ列を割り当てたりします |

## ファイルと編集

| ボタン | 意味 |
|--------|------|
| Open | 保存済みの作業ファイル（.msc）を開きます |
| Save | 作業内容を .msc ファイルとして保存します |
| Export | キャンバスを SVG として書き出します |
| Undo | 直前の操作を取り消します |
| Redo | 取り消した操作をやり直します |

## 描画ツール

| ボタン | 意味 |
|--------|------|
| Select | 図形やグループを選択して移動します |
| DirectSelect | 頂点やセグメントなど、図形の一部分を選択します |
| Line | 線を描きます |
| Rect | 長方形を描きます。Shift を押しながらだと正方形になります |
| Ellipse | 楕円を描きます |
| Ring | リング（ドーナツ形）を描きます |
| Pen | 頂点を順にクリックして自由なパスを描きます |
| Text | 文字を入力します |

## データから図形を作る操作

この4つは、図形を1つ選択していて、データが読み込まれているときだけ押せます。押せないときは、どちらかが足りていません。

| ボタン | 意味 |
|--------|------|
| Repeat | 選択した図形を、データの値の数だけ複製します。棒グラフや散布図の点のもとになります |
| Divide | 1つの図形をデータの値の数に分割します |
| Densify | 線やパスに頂点を追加し、折れ線グラフのような形を作れるようにします |
| Classify | 図形をデータの値で分類します |

それぞれの動きは動画で確認できます。

- [繰り返し (Repeat)](../../generate/repeat/)
- [分割 (Divide)](../../generate/divide/)
- [高密度化 (Densify)](../../generate/densify/)

## バインド

プロパティインスペクタで、図形の見た目（高さ、幅、色など）をデータ列に割り当てる操作です。割り当てたプロパティはデータに従って自動で決まり、手では動かせなくなります。解除ボタンで元に戻せます。手順は[データを視覚的プロパティにバインドする](../../encode/bind/)を参照してください。
