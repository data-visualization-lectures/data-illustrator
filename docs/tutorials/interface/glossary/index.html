    用語集

    アプリの画面は英語のままです。ここでは、画面に出る表記が何を指すかをまとめています。

    画面の5つの領域#

    英語日本語役割
    Tool Barツールバー画面上部。ファイル操作、描画ツール、データ操作のボタンが並びます
    Canvasキャンバス図形を描き、選択し、動かす場所です
    Data Panelデータパネル画面左下。読み込んだデータの表を表示します
    Layersレイヤーキャンバス上の図形、グループ、軸、凡例の構成を表示します
    Property Inspectorプロパティインスペクタ画面右側。選択した図形の見た目を変えたり、データ列を割り当てたりします

    ファイルと編集#

    ボタン意味
    Open保存済みの作業ファイル（.msc）を開きます
    Save作業内容を .msc ファイルとして保存します
    Exportキャンバスを SVG として書き出します
    Undo直前の操作を取り消します
    Redo取り消した操作をやり直します

    描画ツール#

    ボタン意味
    Select図形やグループを選択して移動します
    DirectSelect頂点やセグメントなど、図形の一部分を選択します
    Line線を描きます
    Rect長方形を描きます。Shift を押しながらだと正方形になります
    Ellipse楕円を描きます
    Ringリング（ドーナツ形）を描きます
    Pen頂点を順にクリックして自由なパスを描きます
    Text文字を入力します

    データから図形を作る操作#

    この4つは、図形を1つ選択していて、データが読み込まれているときだけ押せます。押せないときは、どちらかが足りていません。

    ボタン意味
    Repeat選択した図形を、データの値の数だけ複製します。棒グラフや散布図の点のもとになります
    Divide1つの図形をデータの値の数に分割します
    Densify線やパスに頂点を追加し、折れ線グラフのような形を作れるようにします
    Classify図形をデータの値で分類します

    それぞれの動きは動画で確認できます。

    • 繰り返し (Repeat)
    • 分割 (Divide)
    • 高密度化 (Densify)

    バインド#

    プロパティインスペクタで、図形の見た目（高さ、幅、色など）をデータ列に割り当てる操作です。割り当てたプロパティはデータに従って自動で決まり、手では動かせなくなります。解除ボタンで元に戻せます。手順はデータを視覚的プロパティにバインドするを参照してください。
